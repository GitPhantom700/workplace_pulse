Frequently Asked Questions

Architecture, security, runbooks, and telemetry documentation.

🤖 How does the Gemini AI forecasting core work? ▼

WorkplacePulse ingests operational logs from Okta, Jamf, Zoom, Figma, and Jira, standardizing them into a Universal Telemetry Format. Grounded telemetry is passed to a resilient Gemini model fallback ladder (gemini-1.5-flash with auto-failover to gemini-2.0-flash) to identify idle SaaS seats, predict hardware failure risks, and forecast service desk surges.

🔑 How does Bring Your Own Key (BYOK) mode protect my API key? ▼

In BYOK mode, your Gemini API key is stored strictly in temporary browser memory (sessionStorage) and transmitted per-request via the X-Gemini-API-Key header. It is never written to backend databases, server logs, or persistent disk storage.

⚡ How do Automated Runbooks and Webhooks work? ▼

Runbooks automate incident resolution with one-click approvals (e.g., deprovisioning idle licenses or triggering hardware depot RMAs). Each runbook logs an immutable audit event to Firestore and dispatches HMAC-SHA256 signed payloads to registered Slack, Teams, or custom webhooks with automatic exponential backoff retries.

☁️ How does authentication work in Google Cloud Run vs Demo mode? ▼

When deployed to Google Cloud Run, WorkplacePulse automatically utilizes Application Default Credentials (ADC) via an attached Service Account with Vertex AI permissions (roles/aiplatform.user). In local evaluation mode, a high-fidelity simulation engine enables seamless testing without requiring cloud credentials.

🔌 Which enterprise data sources and connectors are supported? ▼

WorkplacePulse supports Okta Universal Directory (SSO & SCIM), Figma Enterprise (seat utilization), Zoom Pro (meeting analytics), Jamf Pro (Apple fleet MDM telemetry), and Jira Service Management (ITSM queue metrics). Connectors can be individually connected, re-synced, or disconnected in the Data Sources tab.

🛡️ How does multi-tenant isolation and Firestore Zero-Trust work? ▼

All tenant documents (forecast logs, webhooks, delivery logs, runbooks) are isolated under user-scoped paths (/users/{userId}/...) enforced by strict Cloud Firestore Security Rules. Cross-tenant reads and IDOR tampering attempts are rejected at the database layer.

📄 How does Executive PDF Report Export work? ▼

The PDF export pipeline dynamically captures high-resolution Chart.js canvas renderings as embedded images, eliminates awkward CSS page breaks, and produces a clean, C-level executive audit document suitable for stakeholder review.
